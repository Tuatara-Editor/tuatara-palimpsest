* Every command and setting

Each command and setting of palimpsest, to look one up by name.

The tables are made from the program each time this manual is made, so they
never list a command or setting that palimpsest does not have. The first table
has four columns. The first two are keys: the modal keys, which work only with
modal editing on, and the non-modal keys, which work with it off too. A command
with no key says ~M-x~ and its name in the second column, because you can only
run it by its name. The third column is the name of the command and the fourth
says what it does.

To run a command by its name, press ~M-x~, type a few letters of the name and
press ~RET~. To find a command from within the editor, press ~C-h f~. To find
the command that a key runs, press ~C-h k~ and then the key. The editor's own
settings and commands are in chapters 21 and 22 of its manual.

** One-letter keys

palimpsest binds no key of one character, so that its keys never clash with
yours. Its commands are on ~C-c~ keys in the report on a PDF: ~C-c d~, ~C-c o~,
~C-c s~, ~C-c w~, ~C-c R~, ~C-c Q~, ~C-c D~, ~C-c c~, ~C-c t~, ~C-c T~ and
~C-c g~. To have one-letter keys too, put these lines in your init file, inside
the =load-package "palimpsest"= form after its =:config=, so that they run once
the package is loaded:

#+begin_src lisp
(bind-key "d" 'palimpsest-draw-objects :map 'palimpsest-mode)
(bind-key "o" 'palimpsest-show-object :map 'palimpsest-mode)
(bind-key "s" 'palimpsest-save :map 'palimpsest-mode)
(bind-key "E" 'palimpsest-write-revision :map 'palimpsest-mode)
(bind-key "R" 'palimpsest-write-report :map 'palimpsest-mode)
(bind-key "Q" 'palimpsest-quit :map 'palimpsest-mode)
(bind-key "D" 'palimpsest-write-drawing :map 'palimpsest-mode)
(bind-key "c" 'palimpsest-group-cases :map 'palimpsest-mode)
(bind-key "t" 'palimpsest-show-shapes :map 'palimpsest-mode)
(bind-key "T" 'palimpsest-write-shapes :map 'palimpsest-mode)
(bind-key "G" 'palimpsest-compare-genuine :map 'palimpsest-mode)
#+end_src

~w~ and ~g~ are left out: in the report they move by words and begin ~g g~ and
~g e~, so writing a revision is ~E~ and comparing with known-genuine files is
~G~.
